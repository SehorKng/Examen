📐 Standards

Les règles du Web

Une page web s'affiche presque pareil sur ton téléphone, ton ordinateur et celui d'un ami. Ce n'est pas un hasard : tout le monde suit les mêmes règles, appelées standards.

🏛️ Qui écrit les règles ?

Personne n'est « propriétaire » du Web. Plusieurs organisations se partagent le travail.

🌐

W3C

Depuis 1994

Créé par Tim Berners-Lee. Publie des recommandations pour HTML, CSS et l'accessibilité.

🦊

WHATWG

Depuis 2004

Créé par des équipes de navigateurs (Apple, Mozilla, Opera). Maintient le standard « vivant » de HTML. Depuis 2019, le W3C et le WHATWG travaillent ensemble sur HTML.

📡

IETF

Protocoles d'Internet

Écrit des protocoles comme HTTP, dans des documents appelés RFC.

⚙️

Ecma International

JavaScript

Standardise ECMAScript, c'est-à-dire le langage JavaScript.

🔀 Avant / après : la même page

Voici le même code de page affiché dans deux navigateurs. Bascule entre les deux mondes.

🎯 Pourquoi c'est important ?

🧭 Compatibilité

Un seul code fonctionne partout. Sans règles communes, il faudrait écrire une version de chaque site par navigateur.

♿ Accessibilité

Les standards permettent aux lecteurs d'écran et aux outils d'aide de comprendre les pages.

⏳ Durée de vie

Une page écrite selon les standards fonctionne encore des années plus tard.

💡

À retenir. Sans standards, certains sites ne marcheraient que chez un seul éditeur de navigateur. Grâce à eux, le Web reste ouvert à tous.
